TRIDENT READ-ONLY SECURITY CONSOLE

静态证据，
而不是猜测。

TRIDENT 把 Java 项目的依赖、HTTP 入口、数据流与访问控制编译成可核对的证据。每一条结论都带出处，可以回跳到源码行号。

  • 只读快照源目录零写入，快照按 SHA-256 定位
  • 分析零外呼静态分析不调用模型、不访问目标
  • 证据账本结论只能引用工具实际读过的行
  • 确定性导出同一快照、同一二进制，字节一致
